## Active project

**[Activist Pixel Sim](pixel-simulator-game/)** — local-first activist-investor pixel RPG (Vite + React + Phaser 3, FastAPI). Phases 0–6 POC complete, plus boardroom meetings on beats 4 / 7 / 9.

**Run:** two terminals from `pixel-simulator-game/` — backend `cd backend && uvicorn app.main:app --reload --port 8000`, frontend `cd frontend && npm run dev` — then open [http://localhost:5173](http://localhost:5173). Full steps: [`pixel-simulator-game/README.md`](pixel-simulator-game/README.md). Contracts: [`SPEC.md`](pixel-simulator-game/SPEC.md).
